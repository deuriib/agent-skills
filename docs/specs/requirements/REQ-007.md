## Description

Behavior SHALL be preserved exactly: `--depth=N` (default 3) hard-caps new `AGENTS.md` depth counting from project root (`./` = depth 0); `--max-depth=N` is an alias of `--depth` (oMo compat); when both appear the LAST one wins; `--create-new` reads all existing files first (preserve context) and deletes/regenerates only after reading; default without flags is update mode. `$ARGUMENTS` parsing happens first.

## Acceptance

- [ ] Compat tests: default=3, `--depth=2` caps at 2, `--max-depth=2` identical, `--depth=5 --max-depth=2` → 2 (last wins) and reverse → 5, `--create-new` log shows read-before-delete.
- [ ] Depth-from-root rule (`./`=0, never exceed cap) exercised on a 4-deep fixture.
